개인정보처리방침

시행일: 2026년 10월 21일

1. 사용 목적

이 앱은 운영자 본인의 유튜브 채널에 영상을 올리고, 그 채널의 영상 통계(조회수·시청자 분포 등)를 확인하는 데에만 Google 계정 권한(YouTube Data API, YouTube Analytics API)을 사용합니다.

2. 수집하는 정보

운영자 본인 계정의 접근 권한 토큰과 운영자 채널의 영상·통계 정보만 다룹니다. 다른 사람의 개인정보는 수집하지 않습니다.

3. 보관과 공유

접근 권한 토큰은 운영자의 컴퓨터에만 저장되며, 제3자에게 판매·공유·전송하지 않습니다. 통계 정보는 운영자의 채널 운영 판단에만 쓰입니다.

4. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 권한 철회

Google 계정 설정의 「서드 파티 액세스」에서 언제든 이 앱의 권한을 해제할 수 있습니다.
